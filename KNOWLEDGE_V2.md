# Технические характеристики срабатывания — Knowledge Engine v2

## Что добавлено

Новый модуль `engines/knowledge_v2.py` расширяет возможности бота для ответов на технические вопросы о характеристиках автоматических выключателей CNC Electric.

## Какие вопросы теперь понимает бот

### 1. Объяснение характеристик
- "Что такое характеристика срабатывания С?" (с кириллической **С**)
- "Что такое характеристика C?" (с латинской **C**)
- "расшифруй характеристику D"
- "характеристика K что это"
- "C характеристика"

**Ответ бота:**
```
Характеристика C — время-токовая характеристика срабатывания автоматического выключателя.

📊 **Диапазон срабатывания:** 5-10 × In от номинального тока

🔧 **Применение:** Универсальная: смешанные нагрузки, небольшие двигатели

💡 **Описание:** Мгновенное расцепление при токе 5-10 кратном номинальному
```

### 2. Поиск товаров с характеристикой
- "Есть ли товары с характеристикой К?"
- "Какие серии имеют характеристику B?"
- "Найдите автоматы с характеристикой Z"

**Ответ бота:**
```
✅ Характеристика **K** встречается в следующих сериях CNC Electric:

• **YCB6**
• **YCB9**
...

ℹ️ Всего найдено: X серий

📚 Источники: каталог-xxx.parsed.md, стр. 12
```

### 3. Список всех характеристик
- "Какие характеристики бывают у автоматических выключателей?"
- "Список характеристик"
- "Все характеристики"

**Ответ бота:**
```
📋 **Характеристики срабатывания автоматических выключателей:**

**B** (3-5 × In): Активные нагрузки (освещение, розетки)

**C** (5-10 × In): Универсальная: смешанные нагрузки, небольшие двигатели

**D** (10-20 × In): Высокие пусковые токи (трансформаторы, мощные двигатели)

**K** (8-14 × In): Защита двигателей, трансформаторов, индуктивных нагрузок

**Z** (2-3 × In): Полупроводники, электроника, цепи с малыми перегрузками
```

## Кириллические символы

Бот автоматически распознаёт кириллические символлы, которые пользователи часто путают с латинскими:
- Кириллическая **С** → латинская **C**
- Кириллическая **К** → латинская **K**
- Кириллическая **В** → латинская **B**

## Интеграция

Модуль интегрирован в `KnowledgeEngine` через адаптер в `engines/adapters.py`:

```python
class KnowledgeEngine(Engine):
    """Wraps local_catalog.py + knowledge_v2.py — technical Q&A from catalogs."""
    
    def can_handle(self, question: str, context: dict[str, Any]) -> float:
        # Try v2 first (technical terminology)
        if get_technical_answer(question):
            return 1.0
        # Fallback to v1 (max current)
        result = max_nominal_current(question)
        return 1.0 if result else 0.0
```

## Приоритет обработки

1. **Product Engine** — поиск товаров по параметрам
2. **ProductDetail Engine** — поиск по артикулу
3. **Knowledge Engine** — технические вопросы (включая характеристики) ← **НОВОЕ**
4. **AI/RAG Engine** — fallback с OpenAI

## Примеры использования

```python
from engines.knowledge_v2 import answer_technical_question

# Вопрос с кириллической "С"
```
