# Распознавание текста (OCR) для PDF-паспортов — необязательный слой.
#
# Нужен, только если ваши PDF сделаны как картинки (экспорт из CorelDRAW):
# из них не извлекается текст, и без OCR они в базу знаний не попадут.
#
# Кроме этих пакетов Python требуется САМ Tesseract в системе:
#   Windows: установщик https://github.com/UB-Mannheim/tesseract/wiki
#            (при установке ОБЯЗАТЕЛЬНО отметьте языковой пакет Russian).
#            PATH трогать НЕ нужно: бот сам ищет tesseract.exe в папке по
#            умолчанию C:\Program Files\Tesseract-OCR. Если поставили в другое
#            место — пропишите путь в .env: TESSERACT_CMD=C:\...\tesseract.exe
#   Linux:   sudo apt-get install tesseract-ocr tesseract-ocr-rus
#
# Проверить готовность: python -c "import ocr; print(ocr.available())"
# Язык и качество настраиваются: OCR_LANG (по умолч. rus+eng), OCR_DPI (300).
pymupdf>=1.24
pytesseract>=0.3.10
